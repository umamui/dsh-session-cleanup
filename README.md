# dsh-session-cleanup

侧边栏底部的「清理会话」按钮：扫描会话目录，把**空目录、只剩备份的残留目录、没有任何真人消息的会话**列成清单，勾选后删除；删除前逐项重新校验。

## 位置

侧边栏底部的动作按钮区（`sidebar.footer.action`，`order: 5`）。

## 判定类别

| category | 含义 | 可删 |
| --- | --- | --- |
| `empty-dir` | 工作区目录下没有任何条目 | ✅ |
| `log-missing` | 会话目录里没有 `session.v4.jsonl.zstd`，只剩 `.bak-*` | ✅ |
| `no-user-message` | 日志能解码，但 0 条真人消息（只有系统注入的指令记录） | ✅ |
| `has-conversation` | 有真实对话 | ❌ 永不删除 |
| `undecodable` | 解压/解析失败 | ❌ |
| `not-a-directory` | 同名条目不是目录 | ❌ |

另外会列出没有对应会话目录的孤立投影缓存行，可一并清理（删掉后会自动重建）。

## 删除前会再校验一遍

清单只是预览，真正删除前每一项都会重新检查：

1. 路径必须落在会话目录内，出现 `/`、`\`、`..` 或越界一律拒绝；
2. 重新判定类别，不在可删集合里的直接跳过；
3. 最近 15 分钟被写入过的跳过，提示「最近有写入，可能正在使用」；
4. 缓存行只在对应会话目录删除后、且该会话确实不存在时才删。
